FBI Confirms North Korea Behind the $6.3 Billion Binance Theft as the Exchange Covers 95% of Losses and Reopens Withdrawals

What's new since last edition: the official attribution we were waiting for has arrived. The FBI says North Korea's TraderTraitor unit carried out the hack. Binance says it has used its own reserves to cover about 95% of the stolen assets, and phased withdrawals began on Sunday.

Read more

NPR reports that on Saturday, October 31, the FBI confirmed that North Korea carried out the October 29 hack. Investigators had already pointed to the military hacking unit known as TraderTraitor. On the same day, Binance said it had covered about 90% of the affected assets and repeated that it, not its users, will absorb the loss. CNBC stresses that this means Binance has restored backing for the assets. It has not recovered 90% of the funds from the attacker. On Sunday, November 1, Binance raised the figure to about 95%, up from 80% and then 90% in earlier updates, according to crypto.news. Phase one of withdrawals opened between 06:00 and 09:00 UTC, starting with Bitcoin. CBS News reports that by 5 a.m. Eastern, withdrawals had also resumed on Ethereum, BNB, XRP, Base, Dogecoin and Optimism. Binance has not given a timetable for the second phase. Many details are still unclear, including exactly how the attackers got in.

Impact on the tech industry: The official attribution makes US sanctions and Treasury action against laundering channels more likely. It also adds pressure for controls on mixers and cross-chain bridges. Binance can cover a multibillion-dollar loss from its own balance sheet, but smaller exchanges could not. Critics cited by NPR say the way exchanges are set up deserves scrutiny, which points regulators toward reserve and insurance requirements. Watch the phase-two timetable, any net outflows as withdrawals reopen, and Binance's root-cause report.

DeepSeek Open-Sources "Super-Agent," a Coding Agent That Watches Team Chats and Proposes Fixes Without Being Asked

The Chinese lab is aiming the MIT-licensed prototype at Anthropic's Claude Code. It works on a GitHub repository and can monitor developer group chats, picking up feedback on its own. DeepSeek calls it a research prototype, not an official product.

Read more

DeepSeek's Harness team described Super-Agent in a WeChat post on Saturday, October 31, and published the code on GitHub as dsh-superagent under an MIT license. The agent is attached to a single GitHub repository. It can also listen to Feishu, ByteDance's workplace chat app, where it picks up coding problems that developers discuss and suggests solutions without being prompted. AI Weekly says it opens work items in parallel worker sessions under a persistent router and replies with pull requests. It reports the repository passed 4,000 GitHub stars within a day. DeepSeek's stated design goal is to take up as little human attention as possible. It also warns that an agent working for a whole team can waste the whole team's attention, and it tells users to review the code before running it. The public version differs from the one DeepSeek uses internally. Bloomberg reports that DeepSeek set up the Harness team this year to compete with coding tools from US labs.

Impact on the tech industry: Coding agents are moving from tools a developer calls on to background teammates that act on their own. That puts pressure on paid products from Anthropic, OpenAI, Cursor and GitHub, because a free, modifiable alternative now exists. An agent that reads team chats also raises new security and data-governance questions for companies. Watch whether DeepSeek ships an official product, adoption outside China, and US restrictions on DeepSeek software.

Sam on AI · Deep Gains · Policy · Oct 31

AI Companies Back a Shared robots.txt Signal That Lets Websites Opt Out of AI Training, but Start Dates Vary

The new signal gives publishers one way to state AI-training preferences across participating providers. Microsoft says it will honor the signal starting February 1, 2027. OpenAI says only that it will implement it in the coming months.

Read more

Deep Gains reports that four AI labs have agreed to support a single opt-out signal for AI training. Sam on AI says the proposal adds a token, usage_ai-training, to a User-Agent group in a site's robots.txt file. Allow and Disallow rules then state the publisher's preference for specific paths. The signal covers how content is used, not whether a crawler may access it. Crawler access is still governed by separate rules, and OpenAI says its existing crawler controls stay in place. Rollout is staggered. Microsoft says its new preferences take effect from February 1, 2027 as it crawls pages. OpenAI says it plans to implement the signal in the coming months. Compliance is voluntary, and the proposal is an individual Internet-Draft that the IETF has not endorsed. In the same briefing, OpenAI's Python SDK 3.42.0 added agent controls, including context compaction and session review.

Impact on the tech industry: Publishers, already losing search traffic to AI answers, get one standard switch instead of a list of bot-specific rules. Because the start dates differ, sites will have to manage a transition period. Because the signal is voluntary, regulators and courts, especially in the EU, will judge whether it counts as a meaningful opt-out under copyright rules. Watch which other labs sign on and whether the IETF takes up the draft.
